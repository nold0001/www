BEFORE YOU START

現在は Windows PC 用トライアルのみお申し込みいただけます

トライアルのインストーラーは 64ビット Windows 用のひとつだけです。Linux 版 tdoctor と Android アプリはトライアルに含まれていません。必要な場合はお問い合わせください。お申し込みの前に、以下の動作環境をご確認ください。

Windows のバージョンWindows 10 · Windows 11 (64ビット) · Home · Pro · Enterprise のいずれにも対応します。Snapdragon などの Windows 11 ARM PC では x64 エミュレーションで動作します。
対応していない環境Windows 7 · 8.1、32ビット Windows、macOS、Linux PC
CPU · メモリ64ビット CPU · メモリ 4GB 以上を推奨
ディスク空き容量 500MB 以上(インストール後は約 120MB、更新時に以前のバージョンを保管します)
画面1366 × 768 以上を推奨(1920 × 1080 以上ならダッシュボードをひと目で見渡せます)
権限インストールには管理者権限が必要です(「このアプリがデバイスに変更を加えることを許可しますか?」で [はい])。会社の PC で制限されている場合は、IT 担当者にご依頼ください。
インターネットインストール・ライセンス確認・更新のために、update.ess.center(HTTPS、443番ポート)への外向きの接続が必要です。
tems サーバーに接続する場合オフラインモードは PC だけで使えます。サーバーをリモートで運用するには、tems サーバーに brontod があり、PC からそのサーバーに届く社内ネットワークまたは VPN が必要です。
HOW TO START

申し込みからインストールまで4ステップ、5分で完了

トライアルは決められたポリシーですぐに開通します。担当者の承認を待つ必要はありません。

申し込み

[トライアルを申し込む] を押して名前・メールアドレスを入力し(会社・連絡先は任意)、個人情報の収集・利用に同意します。

メール認証

メール 「[tdoctor] 평가판 이메일 확인」(メール確認、韓国語)のリンクを開き、[평가판 시작](トライアル開始)を押します。

インストーラーの取得

[Windows 설치 파일 내려받기](Windows インストーラーをダウンロード)を押します。同じリンクがメールでも届きます。インストールキーは7日間、PC 1台で使用できます。

実行

ダウンロードした tdoctor-setup-....exe ファイルを実行し、「このアプリがデバイスに変更を加えることを許可しますか?」で [はい] を押します。タスクバーに tVault アイコンが表示されれば、インストールは完了です。

WHAT YOU CAN TRY

トライアルで試せること

トライアルは Pro エディションです。複数のノードに一度にファイルを配布し、サーバー作業を実行する機能まで、すべて利用できます。

オフラインですぐに

サーバーがなくても大丈夫です。接続画面の [オフラインで開く…] で PC 上の tems 設定フォルダーを開き、環境チェックと設定編集をお試しください。

tems サーバーに接続して

運用中の tems サーバーに brontod があれば、接続してダッシュボード・モニタリング・プロセス制御・ファイル配布・サーバー作業まで、実際の運用の流れを確認できます。

自動更新

トライアル期間中に新しいバージョンが出ると、通知領域の tVault アイコンがお知らせします。今すぐ・あとで・スキップを選択でき、変更内容も確認できます。

事前にお知らせします

FAQ

よくある質問

認証メールが届きません。

まず迷惑メールフォルダー・プロモーションフォルダーで件名 「[tdoctor] 평가판 이메일 확인」 を探してください。それでも見つからない場合は、contact@bronto.co.kr へ申し込みに使ったメールアドレスをお知らせください。

tdoctor だけで使えますか? サーバーは必要ですか?

オフラインモード(環境チェック・設定編集)は tdoctor だけで使えます。サーバーをリモートで運用するには、tems サーバーに brontod が必要です。テストサーバーが必要な場合はお問い合わせください。

別の PC にもインストールできますか?

トライアルは1件のお申し込みにつき PC 1台です。同じメールアドレスで再度申し込んだり、同じ PC でメールアドレスだけを変えて再取得したりすることはできません。複数台で試したい場合はお問い合わせください。

インストールしたプログラムをコピーして別の PC で実行したら?

ライセンスは署名付きトークンと PC 固有の値で確認します。コピーしたプログラムはトライアル期間に関係なく「コピー」と表示され、短い期間しか使えず、まもなく使用できなくなります。

Mac · Linux や Windows 7 でも使えますか?

現在のトライアルは Windows 10 · 11 (64ビット) PC にのみインストールできます。Linux 版 tdoctor は正式ライセンスで提供していますので、Linux で評価したい場合はお問い合わせください。

Android アプリにもトライアルはありますか?

このトライアルは Windows PC 1台用のため、Android アプリは含まれていません。正式ライセンスでは、アカウントごとに PC 1台とスマートフォン1台を併用できます。評価中にスマートフォンの画面もご覧になりたい場合はお問い合わせください。

アンインストールしたい。

Windows の [設定] → [アプリ] で tdoctor と tVault Agent を [アンインストール] するか、通知領域の tdoctor アイコンのメニューから [tdoctor Uninstall] を選びます。

私の情報はどのように使われますか?

トライアルの提供、インストール・期間の案内メール、お問い合わせへの対応にのみ使用し、トライアル終了から1年後に削除します。広告のお知らせは別途同意いただいた場合にのみ送信し、いつでも配信停止できます。詳しくは個人情報保護方針をご覧ください。
