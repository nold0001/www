HOW TO START

From application to installation in 4 steps and 5 minutes

Trials open immediately under a set policy. There is no waiting for approval from our staff.

Apply

Press [Apply for the trial], enter your name and email (company and phone are optional) and agree to the collection and use of personal information.

Verify your email

Open the link in the email "[tdoctor] 평가판 이메일 확인" (email verification, in Korean) and press [평가판 시작] (Start trial).

Download the installer

Press [Windows 설치 파일 내려받기] (Download the Windows installer). The same link also arrives by email. The install key can be used on 1 PC for 7 days.

Run

Run the downloaded tdoctor-setup-....exe file, and press [Yes] at "Do you want to allow this app to make changes to your device?". When the tVault icon appears on the taskbar, installation is complete.

FAQ

FAQ

The verification email did not arrive.

First look in your spam and promotions folders for the subject "[tdoctor] 평가판 이메일 확인". If it is still not there, send the email address you applied with to contact@bronto.co.kr.

Can I use tdoctor on its own? Do I need a server?

Offline mode (environment check and configuration editing) works with tdoctor alone. To operate servers remotely, the tems server needs brontod. If you need a test server, please contact us.

Can I install it on another PC too?

The trial is 1 PC per application. You cannot apply again with the same email, or get another one on the same PC by changing only the email. To try it on several PCs, please contact us.

What if I copy the installed program and run it on another PC?

Licenses are verified with signed tokens and a PC-specific value. A copied program is marked as a "copy" regardless of the trial period, can only be used for a short time, and soon stops working.

Can I use it on a Mac, Linux or Windows 7?

The current trial installs only on Windows 10 · 11 (64-bit) PCs. The Linux version of tdoctor is provided with a full license; if you would like to evaluate it on Linux, please contact us.

Is there a trial of the Android app?

This trial is for 1 Windows PC and does not include the Android app. A full license lets each account use 1 PC and 1 phone together. If you would also like to see the phone app during your evaluation, please contact us.

I want to uninstall it.

Remove tdoctor and tVault Agent in Windows [Settings] → [Apps], or choose [tdoctor Uninstall] from the tdoctor icon menu in the notification area.

How is my information used?

It is used only to provide the trial, send installation and term notices, and answer inquiries, and it is deleted 1 year after the trial ends. Promotional news is sent only if you separately agree, and you can unsubscribe at any time. For details, see our privacy policy.
